Headless `claude -p`: no --bare, cwd outside the repo, per-model fallback chain

2026-08-21 · Coding agents#claude-code#headless#bare#fallback#rate-limit

Superseded. The current rule is Fallback between models sharing one subscription quota protects nothing.

Symptom

claude -p --bare ... answered Not logged in · Please run /login despite a working login; later You've reached your ... limit for one model stopped the automation mid-run.

Cause

--bare skips loading the settings where the subscription's OAuth session lives; the limit is counted per model.

Rule

For headless calls use claude -p --no-session-persistence --output-format json --json-schema ... without --bare, with cwd outside the repo (so the project CLAUDE.md is not pulled in) and with the nested session's CLAUDE* variables cleared; set the model explicitly and keep a fallback chain (sonnet to opus to haiku), switching on the error text (limit|overloaded|429|quota).
