Field notes — symptom → cause → rule, from an unattended browser-automation stack

Size the VPS from measured PSS at peak, not from the cheapest plan

2026-08-22 · Linux services#memory#vps#chrome

Symptom

The migration budget had been set to the cheapest VPS tier, i.e. 1 vCPU and 1-2 GB RAM.

Cause

The plan was chosen by price, not by the load profile. The pipeline keeps a headful Chrome running and launches up to two headless model CLI calls in a row.

Rule

Measure PSS before renting and size for the peak, not the average. Measured: Chrome with two tabs 1.0 GB PSS (28 processes), each headless CLI call 230-520 MB, pipeline peak about 2.2 GB, so a minimum of 2 vCPU / 4 GB. On the cheapest tier the OOM kill would land exactly at submission time, the one minute everything is built for.
