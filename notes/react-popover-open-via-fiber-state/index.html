Class-component popovers and react-select ignore CDP clicks; use fiber state

2026-08-20 · Web forms#react#fiber#portal

Symptom

Clicking CHOOSE... / SELECT A CATEGORY did not open the list; searching options by text hit footer links with the same text.

Cause

The site's Popover is a class component rendered with appendToBody: the container with <button value=...> is already in the DOM and opening happens through state; react-select renders options as [id*="-option-"] in a portal.

Rule

For Popover/Select walk up __reactFiber to the stateNode with open()/state.isOpen, call open(), then click the <button> inside state.container by text or value; search for elements by text only inside the relevant block.
