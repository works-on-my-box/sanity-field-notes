Field notes — symptom → cause → rule, from an unattended browser-automation stack

Take click coordinates after scrolling; register a dialog handler first

2026-09-20 · Puppeteer#click#dialog#confirm

Symptom

Two hangs in one day. (1) Clicks on radio buttons and a text editor had no effect although elementFromPoint showed the right element. (2) After clicking Submit, every page.evaluate hung, then CDP dropped with Network.enable timed out and the tab had to be killed.

Cause

(1) scrollIntoView ran inside the same evaluate that read getBoundingClientRect; the scroll happened, and for a tall element the top moved off-screen, so the click went nowhere. (2) The form shows a native confirm('Are you sure...'); without a dialog handler it blocks the renderer's main thread, so the page, not the script, hangs.

Rule

Take click coordinates in a second call after scrolling and clamp vertically: y = min(max(rect.y + h/2, 140), innerHeight - 140). Attach page.on('dialog', d => d.accept()) before the first click on any submit button, and run the whole form pass as one script without pauses. Signature of this failure: evaluate hangs while curl to the site answers 200 within a second.
