Agent Bash shell lacks Windows interop dirs in PATH: powershell.exe not found

2026-08-26 · Windows & WSL#wsl#path#powershell#interop

Symptom

The bridge bring-up script printed powershell.exe: command not found and then ten NOT reachable attempts; Chrome never started and no UAC prompt appeared.

Cause

The tool's Bash shell has a PATH without the Windows directories (interop works, but /mnt/c/Windows/System32/... is not on PATH).

Rule

Before bridge scripts run export PATH="$PATH:/mnt/c/Windows/System32/WindowsPowerShell/v1.0:/mnt/c/Windows/System32"; the signature of this failure is a command not found line before the UAC line.

Supersedes Windows interop directories are missing from the Bash tool's PATH.
