Field notes — symptom → cause → rule, from an unattended browser-automation stack

pkill -f <string> kills the agent's own Bash tool shell

2026-08-20 · Shell#pkill#pid-file

Symptom

A command containing pkill -f "...server.js" exits with code 144 and the rest of the chain never runs.

Cause

The pattern matches the command line of the tool's own shell, which contains the same text.

Rule

Kill background processes by port (fuser -k 8787/tcp) or by PID file; do not use pkill -f.
