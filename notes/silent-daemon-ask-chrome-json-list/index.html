When a browser daemon goes silent, ask Chrome (`/json/list`), not the log

2026-08-25 · Chrome & DevTools Protocol#cdp#json-list#evidence

Symptom

The cause of hangs was searched in logs for a day and not found: the log held a single line, timeout.

Cause

The log is written only after a call returns; a hung call writes nothing. The state lived elsewhere: in Chrome itself.

Rule

If a daemon is silent, look first at the state of what it controls: curl -s http://127.0.0.1:9222/json/list showed the tab URL within a second. And leave evidence for yourself: a screenshot, the URL and the renderer's answer on every timeout.
