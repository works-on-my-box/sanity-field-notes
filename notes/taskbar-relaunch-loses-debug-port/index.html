Chrome reopened from the taskbar runs without --remote-debugging-port

2026-09-30 · Chrome & DevTools Protocol#cdp#windows

Symptom

The bridge was up and a tab was open; a minute later /json/list was unreachable: the user had closed the window and reopened the profile from the taskbar, so Chrome started with the same profile folder but without the debugging port.

Cause

The taskbar icon launches Chrome with the profile command only, without the launcher's flags.

Rule

Observe a human's actions in the project window without CDP, by window title (Get-Process ... MainWindowTitle via powershell.exe); the port returns only after a relaunch through the launcher, which kills the window, so do it only once the human is done. Clear a password placed in the clipboard as soon as the flow is cancelled.
