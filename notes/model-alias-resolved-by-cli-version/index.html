`claude -p --model <alias>` is resolved by the CLI version, silently

2026-09-07 · Coding agents#claude-code#logging

Symptom

On the server (CLI 2.1.197) --model opus meant one model and an unknown alias meant the same model with no error, while a full model ID returned 400 version 2.1.251 or newer is required; on the laptop (2.1.263) the same aliases resolved to newer models. The log printed the requested alias, so the substitution was invisible.

Cause

An alias is a convention of a specific CLI version; the wrapper returned model: model || 'default' (what was asked) instead of the modelUsage key from the JSON response (what was used). CLI versions on the two machines had not been compared for weeks.

Rule

Put full model IDs in config; log the real model from modelUsage; after any CLI update run one alias-to-ID check via modelUsage; compare CLI versions on laptop and server at every sync.
