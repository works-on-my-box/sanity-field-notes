SPA buttons under CDP: el.click() and keyboard first, real mouse last

2026-08-20 · Puppeteer#click#keyboard#spa#validation

Superseded. The current rule is Synthetic .click() is ignored by SPA modals; a field re-renders after Ctrl+A.

Symptom

Real mouse clicks (mouse.click) on the SPA's buttons worked only sometimes; Save & Continue in an editor did not post to the server (step data lost on URL change), and dialogs hung after Save.

Cause

Some buttons and dropdowns of the component library do not react to the synthetic CDP mouse stream; plus silent client-side validation (a required category field) with no error message.

Rule

(1) First JS el.click() and keyboard (focus + Enter for dropdowns), mouse last; (2) for editor steps call the Vue component method directly (vm.next(), vm.sendToReview(), found via __vue__ on the button's ancestors) and verify the POST and the URL change; (3) re-read the page after every step, never trust 'clicked'.
