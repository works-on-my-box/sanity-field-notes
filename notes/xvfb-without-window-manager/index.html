Xvfb without a window manager cannot raise a window; rehearse the action

2026-08-25 · Linux services#novnc

Symptom

The fallback path 'a human clicks a verification on the server over noVNC' was rehearsed in the morning and still broken in the afternoon: the needed window could not be brought to the front.

Cause

The rehearsal covered the channel (tunnel, picture, mouse movement), not the whole action. On display :99 there was no window manager: windows cannot be switched, there is no active window, only whatever was placed on top is visible. In a real failure the needed window would be underneath.

Rule

A rehearsal passes only when the final action is performed under the same conditions as the failure (same window, same order, same person). 'Access exists' is not 'it can be done'. Fix: a window-manager unit on the server.
