A Quill editor drops non-ASCII and jumps the caret; insert via insertText

2026-08-20 · Web forms#editor#ascii

Symptom

After typing a description the text came out shuffled in chunks; characters like em dash, bullet, arrow, curly quotes and check marks disappeared; when typing from the keyboard the caret jumped to the start after such a character.

Cause

The editor's fields (Quill description, inputs) filter non-ASCII on input; removing a character resets the selection.

Rule

Normalize all texts for that editor to ASCII before input (bullet to -, arrow to ->, em dash to -, straight quotes); insert the description paragraph by paragraph with execCommand('insertText') plus Enter and verify paragraphs via .ql-editor p, not innerText (Quill doubles line breaks in innerText).
