Field notes — symptom → cause → rule, from an unattended browser-automation stack

Hugging Face measured at ~3 KB/s from both machines (later a one-off)

2026-09-29 · Shell#curl#huggingface#bandwidth

Superseded. The current rule is Measure download speed per CDN and machine before saying 'cannot download'.

Symptom

A venv with torch installed in minutes, but a 548 MB model file reached only 200 MB after 25 minutes; curl measured 3026 B/s locally and 2593 B/s on the server.

Cause

The channel to huggingface.co from this region looked narrow (and rate-limited without a token). Later the same day the measurement turned out to be a one-off: 20-32 MB/s from both machines.

Rule

Do not plan downloads above 100 MB within a session; if a large model is needed, fetch it in advance through another channel (mirror, token, another machine).
