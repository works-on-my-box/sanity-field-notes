Gmail IMAP folder names are localized; a wrong name silently reads as empty

2026-10-01 · Email (IMAP/SMTP)#imap#gmail#imapflow

Symptom

A test message was searched in INBOX, [Gmail]/Spam and [Gmail]/All Mail; the script printed Spam: no, All Mail: no, although the message was in All Mail.

Cause

The mailbox has a Russian-language UI, so the folders are named [Gmail]/Спам and [Gmail]/Вся почта. Opening a non-existent folder failed, and the script swallowed the error and treated the folder as empty.

Rule

Pick Gmail folders by specialUse flags (\Junk, \All) from client.list(), not by name; print a folder-open error instead of turning it into not found.
