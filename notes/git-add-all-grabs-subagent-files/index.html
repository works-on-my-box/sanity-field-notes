Field notes — symptom → cause → rule, from an unattended browser-automation stack

git add -A while subagents write to the tree commits their half-done files

2026-10-07 · Coding agents#subagents#claude-code

Symptom

A commit meant for one topic also contained intermediate runs/*.out files from another task, one of them cut off after two lines; subagents were still writing into that directory when the commit was made.

Cause

git add -A stages the whole working tree, and parallel subagents write into the same tree; the parent session committed its own edits without checking what else was changing.

Rule

While subagents are working in the tree, stage only your own paths (git add <files>); use -A only after their reports arrive. Tell a subagent that writes into the repo up front whether it commits its own folder or waits for the parent.
