Two background loops polling the GitHub API burned the 60 requests/hour limit

2026-09-29 · Git#rate-limit#ci#background

Symptom

api.github.com stopped returning JSON with x-ratelimit-remaining: 0; the previous step's background until loop was still running in parallel with the new one.

Cause

Without a token the limit is 60 requests per hour per IP; two loops times 3 requests per minute.

Rule

Check CI status with one request after the expected run time (2-3 min), polling no more than once a minute; before a new loop kill the old one by PID from ps -eo pid,args | grep <sha> (not pkill -f); at remaining: 0 wait for x-ratelimit-reset (date -d @<epoch>).
