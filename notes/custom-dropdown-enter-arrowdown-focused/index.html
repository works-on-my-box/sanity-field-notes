Custom currency input and dropdown: keyboard only; textarea via native setter

2026-08-21 · Web forms#dropdown#keyboard#native-setter#forms

Superseded. The current rule is A custom dropdown: mouse opens but does not select; track document.activeElement.

Symptom

A currency input showed $0.00 after a JS setter; a dropdown option was not selected by JS click or synthetic mouse events on the LI; the toggle stayed at Select a duration.

Cause

The currency component formats its value on keyup/blur and ignores programmatic input; the dropdown listens to keyboard and real mouse.

Rule

Amount: focus + select, Ctrl+A, keyboard.type, Tab. Dropdown: focus the toggle, Enter, ArrowDown until [role=option].is-focused has the wanted text, Enter. Textareas: native setter plus input/change events. Always read the values back.
