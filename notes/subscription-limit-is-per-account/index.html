The subscription session limit is per account, not per machine or model

2026-09-07 · Coding agents#claude-code#rate-limit#daemons

Symptom

A test call from the laptop got You've hit your session limit · resets 10:20pm and the agent session broke for the second time that day; claude auth status on the server showed the same account, so any production call in that window would have hit the limit on every model of the chain.

Cause

The session limit counts per account, not per machine or model; a per-model fallback chain protects against one model's limit, not the account's. A measurement run plus a long agent session exhausted the window in one evening.

Rule

Run measurements in small portions, not while waiting for a client reply or with a draft in progress; search the server for the limit with the (limit) log marker across all logs. A separate account or API key for experiments is a decision for the owner if measurements become regular.
