Windows interop directories are missing from the Bash tool's PATH

2026-08-20 · Windows & WSL#wsl#path#powershell#interop

Superseded. The current rule is Agent Bash shell lacks Windows interop dirs in PATH: powershell.exe not found.

Symptom

The bridge script fails with powershell.exe: command not found even with the sandbox disabled.

Cause

The tool shell's PATH lacks /mnt/c/Windows/System32[/WindowsPowerShell/v1.0].

Rule

Before any bridge or notification scripts run export PATH="$PATH:/mnt/c/Windows/System32:/mnt/c/Windows/System32/WindowsPowerShell/v1.0" (baked into the run script).
