Claude Code blocks foreground sleep; wait with a background until-loop

2026-09-30 · Coding agents#claude-code#monitor#background#waiting

Symptom

sleep 150; ./res.sh was rejected by the harness (Blocked: sleep ... use Monitor); a foreground wait with a 600 s timeout was moved to the background on its own.

Cause

The harness forbids long foreground sleeps.

Rule

Wait for a condition with until <check>; do sleep 20; done run in the background; for an event stream use Monitor (each stdout line becomes a notification, up to 30 minutes, then restart). Long jobs on the server still go through setsid nohup.
