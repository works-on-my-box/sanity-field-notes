Backspace in an empty tag input deletes the previous tag

2026-08-20 · Web forms#typeahead#keyboard#forms

Symptom

When adding skills through a typeahead, after each new tag only that one tag remained.

Cause

Clearing the field with Ctrl+A, Backspace on an empty input removes the last tag: standard tag-input behaviour.

Rule

Clear only when the value is non-empty and use Delete; after each addition re-read the list of tags.
