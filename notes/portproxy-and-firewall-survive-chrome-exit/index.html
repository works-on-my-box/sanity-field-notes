Field notes — symptom → cause → rule, from an unattended browser-automation stack

netsh portproxy and the firewall rule outlive Chrome; no UAC to relaunch

2026-09-30 · Windows & WSL#wsl#cdp

Symptom

The handoff said 'one UAC prompt is the human step'; in practice the CDP port answered right after launching the Chrome launcher alone.

Cause

netsh portproxy entries and the firewall rule survive Chrome closing; admin steps are needed only after a Windows reboot or a change of the WSL interface.

Rule

First check (netsh interface portproxy show all, Get-NetFirewallRule) and run only the Chrome launcher script; run the full bring-up with UAC only if curl http://<gateway>:<port>/json/version does not return 200.
