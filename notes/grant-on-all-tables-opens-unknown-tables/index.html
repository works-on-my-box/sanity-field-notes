grant on all tables in schema opens tables the demo does not have

2026-09-30 · PostgreSQL#rls

Symptom

On a reviewer's advice the fix revoked and re-granted privileges on all tables in schema public. A second reviewer added a sixth table without policies; after those two lines any logged-in user could read and rewrite it.

Cause

The demo has five tables, so 'all tables' equals 'our tables'; a reader's schema is different. One reviewer's advice was accepted without a probe on a neighbouring case.

Rule

In code meant for publication name objects explicitly; test any 'all objects' command on a schema with one extra object. A reviewer's suggestion is a hypothesis like your own: counter-probe before applying.
