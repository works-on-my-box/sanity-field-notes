Field notes — symptom → cause → rule, from an unattended browser-automation stack

A silent slice(0, N) on the way to a model reads as 'nothing more was written'

2026-08-26 · Coding agents#llm-input#parsing

Symptom

6 of 33 descriptions in a day reached the model at exactly 3000 characters, and a job was skipped with 'truncated technical overview without a list of what is needed': the list was beyond the cut.

Cause

The parser cut summary at 3000 characters silently; the prompt received the length and the source but not the fact of truncation, so the model read the cut as 'the client did not describe the task'. The mirror case (short is not unread) had been fixed earlier without looking at the other end of the distribution.

Rule

Any slice(0, N) on the way to a model must (a) set the limit from the distribution with headroom, (b) leave a marker in the text ([truncated at N of M characters]), (c) reach the prompt as a fact. When fixing one end of a threshold, check the other end.
