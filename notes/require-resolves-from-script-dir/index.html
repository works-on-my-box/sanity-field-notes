Field notes — symptom → cause → rule, from an unattended browser-automation stack

require('./x') resolves from the script's directory, fs paths from cwd

2026-09-27 · Node.js#node

Symptom

A one-off probe run as cd ~/app && node /tmp/probe.js failed with Cannot find module './lib/sample', while files under state/ were read fine.

Cause

require('./x') is resolved relative to the file that calls it (/tmp), whereas fs.readFileSync('state/...') is relative to the current working directory.

Rule

In one-off scripts outside the repo, require project modules by absolute path (require('/abs/path/to/lib/sample')); keep data paths relative to cwd or absolute as well.
