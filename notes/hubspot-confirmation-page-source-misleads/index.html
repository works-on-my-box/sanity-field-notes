Field notes — symptom → cause → rule, from an unattended browser-automation stack

HubSpot preference pages embed every outcome; read only the visible text

2026-10-05 · Web forms#curl

Symptom

Re-checking an address confirmation with curl: the URL path said optin-confirmed, the title said Subscription confirmation, but the page text contained You have successfully unsubscribed from all email communications. In a browser the same page shows only Your email preferences were updated.

Cause

The HubSpot preferences-center template puts all possible outcomes into the HTML and hides the irrelevant ones with script and CSS. A side detail: the saved link contained a space, so curl refused it (URL rejected, exit code 000).

Rule

Read the outcome of a confirmation page (HubSpot and similar) from document.body.innerText in a browser plus the URL path, with a screenshot; never conclude from the raw HTML. Strip whitespace from a link copied out of an email before passing it to curl.
