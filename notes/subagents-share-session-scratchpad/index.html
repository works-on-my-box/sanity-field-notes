Field notes — symptom → cause → rule, from an unattended browser-automation stack

Subagents share the session scratchpad and ask permission to delete their files

2026-09-30 · Coding agents#subagents#claude-code

Symptom

A second 'independent' reviewer worked in the same scratchpad folder as the first, where the first reviewer's files (including its patch) were lying; at the end it requested rm -rf of its own binaries, and the user saw and rejected the permission prompt.

Cause

The task only forbade reading the repository; no draft directory was named and nothing was said about deletion.

Rule

In a subagent task: give it its own directory (/tmp/<role>-<round>/), forbid reading other scratchpad directories, forbid deleting files. Before a repeat round, remove or rename the previous round's folders.
