Field notes — symptom → cause → rule, from an unattended browser-automation stack

A web-research subagent paraphrases sources and marks its own facts verified

2026-09-13 · Coding agents#subagents#claude-code

Symptom

A weekly staleness check was done by a subagent (19 web calls); its report carried check marks. The facts were copied into the review, the wiki log and the handoff with the caveat 'per the subagent'. Verifying the primary sources before the summary found two errors out of six: two quarterly percentages were wrong by several points, and a changelog claim about existing database tables was inverted (the changelog said existing tables were not affected); the subagent's link led to a 404.

Cause

The subagent retells secondary sources and awards itself check marks. Retelling loses caveats (existing tables are not affected) and mixes up metrics from neighbouring lines of a report. The 'per the subagent' caveat does not stop the error from entering long-term memory and conclusions.

Rule

A fact from a web subagent enters project memory only after the agent itself opened the primary source (press release, changelog, the platform's own help) and checked the quote. Not verified means not written. Demand verbatim quotes with URLs from the subagent, not a retelling. Verify before writing, not before the summary.
