psql heredoc: a bare echo line swallows begin; the probe runs untransacted

2026-09-30 · PostgreSQL#psql

Symptom

A truncate public.comments probe inside a supposedly rolled-back transaction emptied the table in the test database: ROLLBACK answered there is no transaction in progress.

Cause

A line echo (without the backslash) was concatenated with the following begin; into one invalid statement; psql without ON_ERROR_STOP kept going.

Rule

Destructive probes only on a copy of the database and with \set ON_ERROR_STOP on; labels only via \echo; after begin, check select pg_current_xact_id_if_assigned() is not null or read the output before the probe.
