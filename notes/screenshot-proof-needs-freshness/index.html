Field notes — symptom → cause → rule, from an unattended browser-automation stack

A screenshot sent as evidence must prove it was taken now

2026-08-25 · Puppeteer#evidence#race#timeouts#alerts

Symptom

An alert went out with an image captioned 'what is on screen' that had nothing to do with what was on screen.

Cause

The screenshot was written to the same file every time, and on a wedged renderer screenshot did not return within the allotted 10 s. The race moved on, the path still went into the error text, and the previous frame was sent.

Rule

An artifact sent as proof must carry a freshness signal (it was captured right now). If it could not be captured, say so in words; never send 'the latest available' in place of the current one.
